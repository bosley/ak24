## Modern Doxygen Features Used

### 1. Javadoc-Style Comments
```c
/**
 * @brief One-line description
 *
 * Detailed description with markdown support.
 *
 * @param name Parameter description
 * @return Return value description
 */
```

### 2. Custom Thread Safety Aliases
- `@threadsafe` - Thread-safe function
- `@notthreadsafe` - Not thread-safe
- `@lockfree` - Lock-free implementation
- `@waitfree` - Wait-free with bounded time

### 3. Rich Documentation Features
- Markdown support in comments
- Code examples with `@code` blocks
- Cross-references with `@see`
- Named sections with `@par`
- Multiple return values with `@retval`
- Warnings and notes with `@warning` and `@note`

### 4. Modern HTML Output
- Responsive design
- Tree view navigation
- Syntax-highlighted source browser
- Full-text search
- Mobile-friendly

## Documentation Standards

Every public API should have:

1. **File Header**
   - `@file` with filename
   - `@brief` one-line description
   - Detailed overview
   - Key features list

2. **Function Documentation**
   - `@brief` one-liner
   - Detailed description
   - `@param` for all parameters
   - `@return` for return value
   - Thread safety marker
   - Usage example for complex functions

3. **Structure Documentation**
   - `@brief` description
   - Inline `/**< */` comments for fields
   - Purpose and usage notes
